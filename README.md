# Tic-Tac-Toe

A browser tic-tac-toe game that stays comfortable on phones and desktops. Open `index.html` in a browser. There is no build step.

## Play

- Pass a device back and forth, or play X against a perfect machine.
- Undo a move, start a new round, or reset the score for the current mode.
- Switch between light and dark, and mute the move sounds.

Scores and preferences stay in the browser.

## Files

- `index.html` holds the page structure.
- `styles.css` sizes the board to the space left on the screen.
- `game.js` runs the rules, the opponent, and the controls.
- `favicon.svg` is the tab icon.
